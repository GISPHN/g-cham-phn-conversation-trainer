# 特定保健指導版 MVP 要件定義

## 目的
保健師が特定保健指導の対象者との対話を反復練習できる教育用Webアプリを構築する。正解文を覚える教材ではなく、生活背景、健康認識、行動変容の準備状態、過去の支援経験などによって応答が変化するシミュレーション環境を目指す。

## 公的資料との対応
主たる根拠は厚生労働省「標準的な健診・保健指導プログラム（令和6年度版）」とする。対象者の生活習慣、行動変容ステージ、生活・就労環境を把握し、対象者の考えを受け止め、本人が改善点に気付き、自ら具体的な行動目標を設定できるよう支援する構造を実装する。繰り返し対象者では過去の目標、実施状況、続かなかった経験も確認する。

## JMED-Personas
JMED-Personasは対象者背景の生成に利用する。年齢、性別、教育歴、健康リテラシー、職業、経済的制約、BMI、家族関係、社会参加、Big Five、喫煙、飲酒、運動、食生活、睡眠等を候補とする。ただし、これらをそのまま特定保健指導における心理状態とはみなさない。

## 会話状態モデル
trust、readiness、resistance、selfEfficacy、disclosure、concernを教育用内部状態として扱う。実際の対象者の心理を測定する尺度ではない。

## AI方針
MVP 0.1はルールベース状態遷移とテンプレート応答。MVP 0.2でブラウザ内LLMを追加する。状態遷移をLLMだけに任せず、対象者AIと教育評価AIを分離する。医学的事実はシナリオデータを正とする。

## 安全
本アプリは教育用であり、診断、治療、特定保健指導の実施判断を代替しない。実在者の個人情報を入力しない。研究利用時は別途倫理的検討を行う。
