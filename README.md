# G-CHAM PHN Conversation Trainer

保健師が対象者との会話を反復練習するためのWebアプリです。G-CHAMファミリーの教育・シミュレーションツールとして開発しています。

現バージョンは特定保健指導をMVPとし、厚生労働省「標準的な健診・保健指導プログラム（令和6年度版）」の考え方を参考に、対象者理解、行動変容の準備状態の把握、本人主体の目標設定を練習できる構造を目指します。

## 現在の実装

- 特定保健指導3ケース
- 初級、標準、上級
- 対象者の会話内部状態
- 発話の簡易分類
- 状態遷移
- ルールベース応答
- 面接後フィードバック
- GitHub Pages用Workflow

現時点では教育設計と状態遷移を検証するため、LLMはまだ接続していません。

## JMED-Personas

JMED-Personasの内容は個々の医学的妥当性を保証するものとして扱わず、本アプリでは教育用の合成対象者背景として使用します。
